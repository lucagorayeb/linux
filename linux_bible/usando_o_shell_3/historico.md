# Histórico

- Para usar o histórico de comandos passados
  temos que usar as setas de para cima e para
  baixo para olhar os comandos anteriores.

- Para ver os últimos comando e o número que eles 
  represetam na lista. 
        
        history N (N é um número qualquer) 
    
  Dessa forma vai listar os últimos N comandos 
  que foram passados.

- Para executar diretamente um comando passado
  anteriormente sem as setas é preciso saber o 
  número do comando na lista do histórico.

        !N (N é o número da ordem que o comando foi
            passado)
    
        !! (Para executar o último comando passado)

        !?dat? (Roda o comando mais recente que contém 
                a string passada no comando)
