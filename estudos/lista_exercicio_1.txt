TRILHA PRÁTICA LINUX - EXERCÍCIOS COM MAN PAGES
Método:
1. Tente resolver sozinho
2. Se travar, abra o manual com man <comando>
3. Leia só o necessário
4. Teste novamente

==================================================
FASE 1 - FUNDAMENTOS DO TERMINAL
==================================================

EXERCÍCIO 1 - ORGANIZAR DIRETÓRIOS - FEITO

Objetivo:
Aprender navegação e manipulação de arquivos.

Tarefa:
1. Crie a pasta laboratorio
2. Dentro dela crie:
   - docs
   - scripts
   - backup
3. Crie 3 arquivos .txt dentro de docs
4. Mova 1 arquivo para backup

Leia se travar:
man mkdir
man touch
man mv
man ls
man pwd

--------------------------------------------------

EXERCÍCIO 2 - CÓPIA E REMOÇÃO SEGURA  - FEITO

Objetivo:
Aprender copiar e apagar arquivos.

Tarefa:
1. Copie todos arquivos de docs para backup
2. Apague apenas 1 arquivo específico
3. Liste o conteúdo final

Leia se travar:
man cp
man rm
man ls

--------------------------------------------------

EXERCÍCIO 3 - ENCONTRAR ARQUIVOS  - FEITO

Objetivo:
Aprender busca no sistema.

Tarefa:
1. Crie 10 arquivos variados
2. Encontre apenas arquivos .txt
3. Encontre arquivos criados hoje

Leia se travar:
man find
man ls

==================================================
FASE 2 - TEXTO E LOGS
==================================================

EXERCÍCIO 4 - FILTRAR INFORMAÇÕES  - FEITO

Objetivo:
Aprender análise de logs.

Tarefa:
Crie arquivo app.log com conteúdo:

INFO login ok
ERROR banco caiu
INFO logout
ERROR timeout

Depois:
1. Mostrar só linhas ERROR
2. Contar quantas linhas ERROR existem

Leia se travar:
man grep
man wc
man cat

--------------------------------------------------

EXERCÍCIO 5 - EDITAR TEXTO - FEITO

Objetivo:
Substituir texto rapidamente.

Tarefa:
Troque todas ocorrências de ERROR por FALHA no arquivo app.log

Leia se travar:
man sed
