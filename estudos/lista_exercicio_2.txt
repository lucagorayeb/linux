TRILHA PRÁTICA LINUX - NÍVEL 2
DESAFIOS REAIS (INTERMEDIÁRIO / PROFISSIONAL)

Método:
1. Resolva sozinho
2. Se travar: use man pages
3. Investigue logs
4. Teste hipóteses
5. Só depois pesquise

==================================================
FASE 1 - ARQUIVOS E BUSCA REAL
==================================================

EXERCÍCIO 1 - LIMPEZA DE LOGS GIGANTES - FEITO

Objetivo:
Trabalhar com arquivos grandes.

Tarefa:
1. Crie um arquivo log com milhares de linhas
2. Misture INFO, WARN e ERROR
3. Extraia somente ERROR
4. Conte quantos ERROR existem
5. Salve resultado em outro arquivo

Leia se travar:
man seq
man echo
man grep
man wc
man >

--------------------------------------------------

EXERCÍCIO 2 - BACKUP INTELIGENTE - FEITO

Objetivo:
Copiar preservando estrutura.

Tarefa:
1. Crie árvore com pastas e arquivos
2. Faça backup completo
3. Modifique 2 arquivos
4. Faça backup somente do que mudou

Leia se travar:
man cp
man rsync
